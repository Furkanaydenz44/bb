# Bulbana Web

Bu klasor, eski tek dosyalik prototipin cok dosyali yapisidir.

- `index.html`: alici ve satici rolleri arasinda gecis yapan tam ekran demoyu acar.
- `alici.html`: yalniz alici panelini acar.
- `satici.html`: yalniz satici panelini acar.
- `assets/css/app.css`: eski monolit dosyadan cikarilan ana stiller.
- `assets/css/shell.css`: sayfa modu ve kabuk duzeni.
- `assets/js/app.js`: uygulama verisi, render fonksiyonlari ve etkilesimler.
- `route-entry.html`: temiz URL klasorlerinin kullandigi ortak giris.

Temiz URL ornekleri:

- `/bulbana-web/@ahmetsafak/`
- `/bulbana-web/@furkan/kategori/foto/`
- `/bulbana-web/@furkan/ilan/leica-m6-35mm-film-makinesi-ariyorum-d1/`

Orijinal monolit kaynak `../bulbana-web-tam-ekran-uyarli-v1.legacy.html` olarak saklandi.
